Logistic Regression — Application



Problem Context

Hospitals want a simple, fast way to flag patients who may be at higher risk of heart disease, using a measurement already collected during routine blood work. The phenomenon analyzed here is heart disease risk. Each row in the dataset represents one patient, described by their cholesterol level. Each patient also has a label showing whether they were ultimately classified as low or high risk. The purpose of this model is to learn the relationship between cholesterol level and risk, so it can estimate the probability that a new patient falls into the high-risk category. That predicted probability, and the class it maps to, is the value the model attempts to classify.

Train / Test Split

The dataset was split using scikit-learn's train_test_split(). 80% of the records ({{ dataset_info.n_train }} patients) trained the model. The remaining 20% ({{ dataset_info.n_test }} patients) were held out to evaluate it. The model never sees the test set during training, so its performance on that data shows how well it generalizes to new patients.

Logistic Regression Model

A LogisticRegression model from scikit-learn was trained following this pipeline:

CSV Dataset → Pandas → X and y → Feature Scaling → 80/20 Split → Model Training → Predictions → Evaluation → New Classifications

Every classification shown on this page, and in the evaluation section, is generated by this trained model. None are hard-coded. Detailed performance metrics (confusion matrix, accuracy, precision, recall, F1-score) are available on the Evaluation Metrics page.
