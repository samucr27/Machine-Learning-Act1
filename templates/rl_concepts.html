Reinforcement Learning — Concepts



What is Reinforcement Learning?

Reinforcement Learning (RL) is a type of Machine Learning in which an agent learns by interacting with an environment. There is no labeled dataset: the agent tries actions, receives rewards or penalties, and gradually learns a policy that maximizes the expected return.

In this exercise: a virtual robot moves through a 10 × 10 maze looking for the target T, trying to avoid walls and Danger Zones.

The Reinforcement Learning Cycle

1. Agent observes state s
→
2. Chooses action a
(ε-greedy)
→
3. Environment applies the move
→
4. Returns reward r and next state s′
→
5. Q-value update

The cycle repeats until the agent reaches T or the step limit; then a new episode starts.

How Q-Learning Updates a Value

After every step the agent computes a target and moves its estimate toward it:

target = r + γ · max Q(s′, a′)

Q(s, a) ← Q(s, a) + α · (target − Q(s, a))

Implementation: the target is passed to SGDRegressor.partial_fit(), whose learning rate plays the role of α. At the goal T the target is just the goal reward, because the episode ends.
