Reinforcement Learning — Concepts



What is Reinforcement Learning?

Reinforcement Learning (RL) is a branch of Machine Learning where an agent learns purely by interacting with an environment, instead of learning from a fixed labeled dataset. The agent tries an action, sees what happens, and collects a reward or a penalty in response. Repeating this thousands of times lets it build up a policy aimed at maximizing the reward it can expect to earn overall.

In this exercise: a virtual robot moves across a 10 × 10 maze searching for the target T, while trying to steer clear of walls and Danger Zones.

How Q-Learning Updates a Value

After every single step, the agent builds a target value and moves its current estimate a little closer to it:

target = r + γ · max Q(s′, a′)

Q(s, a) ← Q(s, a) + α · (target − Q(s, a))

Implementation: that target value is fed into SGDRegressor.partial_fit(), whose internal learning rate plays the role of α. At the target cell T the target is simply the goal reward, since the episode ends there and there is no next state to consider.
