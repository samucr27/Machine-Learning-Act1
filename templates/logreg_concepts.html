Logistic Regression — Concepts



What is Logistic Regression?

Logistic Regression is a supervised classification algorithm, even though its name includes the word "regression." Instead of predicting a continuous number, it predicts the probability that an observation belongs to a given class. That probability is then converted into a final class prediction. It is one of the most widely used algorithms for problems where the outcome is a category rather than a quantity.

Why Is It a Classification Algorithm?

Logistic Regression takes one or more input variables and passes their weighted combination through a function called the sigmoid function. This function squeezes any numeric result into a value between 0 and 1, which can be interpreted as a probability. Since the final output is a class label (not a numeric quantity), the algorithm is classified as a classification method, not a regression method in the traditional sense.

Binary Classification

Binary classification refers to problems where there are only two possible outcomes or classes. Logistic Regression, in its basic form, is designed for exactly this type of problem. In this project, the two possible outcomes are Low Risk and High Risk of heart disease. Each patient in the dataset belongs to exactly one of these two classes.

Key Concepts

1 Independent variable: the input used to make a prediction. In this project, it is the patient's cholesterol level (mg/dL).
2 Dependent (target) variable: the outcome being predicted. Here, it is the patient's heart disease risk.
3 Classes or labels: the possible categories the target variable can take. In this case, 0 (Low Risk) and 1 (High Risk).
4 Probability of belonging to a class: the sigmoid function outputs a number between 0 and 1, representing how likely it is that the observation belongs to the "High Risk" class.
5 Classification threshold: the cutoff point (commonly 0.5) used to convert a probability into a final class. If the probability is above the threshold, the model predicts High Risk; otherwise, it predicts Low Risk.

Linear Regression vs. Logistic Regression

Linear Regression

  • Predicts a continuous numeric value.
  • Output can range from negative to positive infinity.
  • Fits a straight line to the data.
  • Used for problems like predicting price, temperature, or age.

Logistic Regression

  • Predicts the probability of belonging to a class.
  • Output is always between 0 and 1.
  • Fits an S-shaped sigmoid curve to the data.
  • Used for problems like predicting risk, spam, or approval.

In short, Linear Regression answers "how much?", while Logistic Regression answers "which class?" — even though both algorithms share a similar underlying mathematical structure.

A Real-World Example

A hospital records the cholesterol level of many patients, along with whether each patient was ultimately diagnosed as low or high risk for heart disease. Logistic Regression learns the relationship between cholesterol level and risk from this historical data. Once trained, it can estimate the probability that a new patient, given only their cholesterol level, falls into the high-risk category. This is the case implemented in the Application page.
