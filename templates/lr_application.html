Linear Regression Application



Problem Context

Electric utility companies want to anticipate how much electricity will be consumed on a given day, so they can plan supply and manage costs. The phenomenon analyzed here is the relationship between daily temperature and electricity consumption: the data shows that consumption tends to rise on colder days, most likely because heating systems are used more heavily as temperature drops. Each row in the dataset represents one day, described by its average temperature (calculated from the day's maximum and minimum readings) and the electricity consumed that day. The purpose of applying Linear Regression here is to learn the general trend behind that relationship, so that the model can predict how much electricity will be consumed per day based on the value it is trying to predict, using only the forecast temperature.

Variables

  • Independent Variable (X): Daily Temperature

    How hot or cold the day was on average, in degrees Celsius (°C). This is the input the model uses to make its prediction.
  • Dependent Variable (Y): Electricity Consumption

    How much electricity was used that day, in kilowatt-hours (kWh/day). This is the value the model tries to predict.
