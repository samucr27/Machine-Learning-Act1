Linear Regression Concepts



What is Linear Regression?

Linear regression is a statistical modeling tool used in machine learning to predict a dependent variable based on a dataset provided to the system. It can be applied to a wide range of scenarios, from simple systems for tracking student grades to complex systems in finance and sports.

Linear regression is represented by line models that show the relationship between the dependent variable (Y) and the independent variable (X). For example, a model to predict a person’s weight based on their height.

Types of Linear Regression

Linear regression can be simple, using a single independent variable to predict the dependent variable, or multiple, using two or more independent variables at once. The application built in this project uses simple linear regression, since a single feature — daily temperature — is used to predict electricity consumption.

What Problems Can Linear Regression Solve?

Linear regression is useful whenever a numeric outcome seems to move consistently along with another numeric factor. Some common use cases:

Estimating how much electricity, water, or fuel will be consumed based on a condition such as temperature, occupancy, or time of year — exactly the case used in this project's Application page.

Estimating the price of a house, a car, or a product based on one of its measurable characteristics, such as size, mileage, or weight.

Projecting future values, such as monthly sales or website traffic, based on how they have changed over time or alongside another measurable factor.

Independent Variable (X)

The independent variable is the input the model already knows — the value the user provides or that is measured directly. It is called "independent" because its value does not depend on any other variable in the model; it is the cause, or the input side, of the relationship. In a graph, it is placed on the horizontal (X) axis. In this project, the independent variable is the daily temperature.

Dependent Variable (Y)

The dependent variable is the value the model tries to predict. It is called "dependent" because its value is assumed to depend on, or be explained by, the independent variable. In a graph, it is placed on the vertical (Y) axis. In this project, the dependent variable is the electricity consumption.

Relationship Between Variables

Linear regression assumes that X and Y move together in a roughly straight-line pattern: as the independent variable increases, the dependent variable tends to increase (a positive relationship) or decrease (a negative relationship) by a fairly consistent amount. Real data is never perfectly aligned to a line — there is always some scatter — but the model looks for the straight line that best summarizes that overall trend. In this project, the relationship is negative: lower daily temperatures tend to come with higher electricity consumption, most likely because heating systems work harder on colder days.
