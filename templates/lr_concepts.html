Linear Regression Concepts



What is Linear Regression?

Linear regression is a statistical modeling tool used in machine learning to predict a dependent variable based on a dataset provided to the system. It can be applied to a wide range of scenarios, from simple systems for tracking student grades to complex systems in finance and sports.

Linear regression is represented by line models that show the relationship between the dependent variable (Y) and the independent variable (X). For example, a model to predict a person’s weight based on their height.

Types of Linear Regression

Linear regression can be simple, using a single independent variable to predict the dependent variable, or multiple, using two or more independent variables at once. The application built in this project uses simple linear regression, since a single feature — daily temperature — is used to predict electricity consumption.
