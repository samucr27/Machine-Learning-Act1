Extra Trees Classifier — Application



Problem Context

Hospitals want a way to flag patients who may need closer attention, using measurements already collected during a check-up. The phenomenon analyzed here is heart disease risk. Each row in the dataset represents one patient, described by four clinical measurements: cholesterol level, age, resting blood pressure, and maximum heart rate achieved. Each patient also has a label showing whether they were ultimately classified as low or high risk. The purpose of this model is to learn the combined pattern across all four measurements, so it can classify a new patient into one of two risk categories. That predicted category is the value the model attempts to classify.

Train / Test Split

The dataset was split using scikit-learn's train_test_split(). 80% of the records ({{ dataset_info.n_train }} patients) trained the model. The remaining 20% ({{ dataset_info.n_test }} patients) were held out to evaluate it. The model never sees the test set during training, so its performance on that data shows how well it generalizes to new patients.

Extra Trees Model

An ExtraTreesClassifier from scikit-learn was trained following this pipeline:

CSV Dataset → Pandas → X and y → 80/20 Split → Model Training → Predictions → Evaluation → New Classifications

Every classification shown on this page, in the evaluation and in the form below, is generated by this trained model. None are hard-coded. Detailed performance metrics (confusion matrix, accuracy, precision, recall, F1-score) are available on the Evaluation Metrics page.
