Reinforcement Learning Application



Problem Context

A virtual robot (the agent) is placed at cell A of a 10 × 10 map and must reach the target T. It is never told the route: it discovers it by trial and error. Each action produces a reward or a penalty, and Q-Learning uses that feedback to learn a policy that maximizes the expected return. The map contains walls, free cells and Danger Zones, which the agent may enter but must learn to avoid.

Environment (10 × 10)

The environment has exactly 100 cells. Coordinates are (row, column), starting at (0, 0).

Environment Logic

After every action the environment determines:

  • Current state: the agent's (row, column).
  • Selected action: Up, Down, Left or Right.
  • Next state: the new position (the agent stays in place after an invalid move or a wall).
  • Type of cell: Start, Path, Wall, Danger Zone, Goal or Invalid move.
  • Reward obtained: taken from the reward table above.
  • Episode ended? Yes when T is reached or when the maximum number of steps is hit.
The agent cannot leave the grid or cross a # wall. It can enter a D cell, but it receives the Danger Zone penalty.

Model: Q(s, a) is estimated with scikit-learn's SGDRegressor. predict() returns the Q-values and partial_fit() updates them after every step.

Train the Agent

Training runs the Q-Learning loop: initial state → action selection (exploration / exploitation) → environment interaction → reward and next state → Q-value update → next action → goal or end of episode. It takes a few seconds.
