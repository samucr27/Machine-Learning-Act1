Types of Machine Learning

Machine Learning algorithms are usually grouped into three broad categories, depending on how the model learns from the data it is given.

Supervised Learning

The model learns from a labeled dataset, where each example already includes the correct answer. The algorithm adjusts itself to reproduce that mapping between inputs and outputs.

Main characteristics

Requires labeled data; performance can be measured directly against known answers; learns a specific input-to-output relationship.

Types of problems

Regression (predicting a numeric value) and classification (assigning an item to a category).

Unsupervised Learning

The model works with unlabeled data and tries to find structure on its own (grouping, patterns, or relationships) without being told what the correct answer looks like.

Main characteristics

No labeled outputs are provided; the model discovers structure rather than reproducing it; results are generally harder to evaluate objectively.

Types of problems

Clustering (grouping similar items) and dimensionality reduction (simplifying data while keeping its structure).

Reinforcement Learning

An agent learns by interacting with an environment, taking actions and receiving rewards or penalties. Over time it learns a strategy that maximizes the reward it accumulates.

Main characteristics

Learns through trial and error; relies on a feedback signal rather than labeled examples; must balance trying new actions against using what already works.

Types of problems

Sequential decision-making, such as game playing, robotics, and process control.
