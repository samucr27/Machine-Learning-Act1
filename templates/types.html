Types of Machine Learning

There are different types of Machine Learning. Each type learns from data in a different way. Below are the four main types.

1. Supervised Learning

In Supervised Learning, the computer learns from data that has labels. A label is the correct answer. The computer sees many examples with answers, and it learns to give answers for new data.

Characteristics: It needs labeled data. It learns to predict a specific answer.

Example: An email app learns to detect spam. It looks at many emails marked as "spam" or "not spam" and learns the pattern.

2. Unsupervised Learning

In Unsupervised Learning, the computer learns from data without labels. There are no correct answers. The computer finds patterns and groups by itself.

Characteristics: It does not need labeled data. It finds hidden patterns or groups in the data.

Example: A store studies customers and groups them by their shopping habits, without knowing the groups in advance.

3. Semi-Supervised Learning

Semi-Supervised Learning is a mix between Supervised and Unsupervised Learning. The computer learns from a small amount of labeled data and a large amount of unlabeled data. It uses the labeled examples as a guide to understand the patterns in the rest of the data.

Characteristics: It needs only a small set of labeled data. It is useful when labeling data is expensive or takes a lot of time.

Example: A voice recognition system learns from a few labeled voice recordings and then uses many more unlabeled recordings to improve its understanding of speech patterns.

Common uses: Voice analysis, fraud detection, and medical research.

4. Reinforcement Learning

In Reinforcement Learning, the computer learns by trying different actions and seeing what happens. It receives a reward when it does something good, and a penalty when it does something wrong. Over time, it learns the best actions to take to get the most rewards.

Characteristics: It learns through trial and error. It does not need labeled data, but it needs an environment where it can act and receive feedback.

Example: A robot learns to walk by trying different movements. Each time it moves correctly, it receives a reward, and this helps it improve over time.

Common uses: Robotics, video games, and resource management.
